# Оформление и экспорт

## Источники Crowd / Gradient

Локальные пути относительно корня Аркадии:

- `crowdsourcing/frontend/projects/assessment/services/gradient-landing/` — лендинг Gradient
- `public/images/bg.svg` в лендинге — оригинальная фоновая графика
- `src/styles/globals.css` и `src/blocks/` — шрифты, отступы и композиция
- `crowdsourcing/frontend/projects/assessment/packages/commons/src/themes/color/primitives.css` и `crowd-ds.css` — цветовые токены

Для чтения Аркадии используй доступный профильный скилл. Ищи в точном каталоге, не перечисляй весь монорепозиторий. Библиотеку React-компонентов не нужно устанавливать ради статичных картинок: HTML/CSS со стилями и оригинальными ассетами подходит для такого результата. Не называй это сборкой на компонентах Gradient, если использованы только его стили.

Если локальные исходники недоступны, используй предоставленный референс или описанную ниже палитру и прямо укажи ограничение. Не рисуй имитацию фирменного логотипа. Копируй нужные ассеты в каталог результата, чтобы HTML открывался независимо от исходного чекаута. Не публикуй внутренние ассеты в публичный репозиторий.

Шрифты YS Text и YS Display могут быть установлены локально, например в `/Library/Fonts` на macOS. Подключай найденные файлы через `@font-face`. При отсутствии используй доступный шрифт с кириллицей и сообщи о замене. Не загружай шрифты и не добавляй зависимости без необходимости.

## Базовые значения

| Элемент | Значение по умолчанию |
|---|---|
| Размер слайда | 1440 × 1440 px |
| Внутренние поля | 88 px сверху и снизу, 92 px по сторонам |
| Основной текст | `#17171b`, 34–40 px, интерлиньяж 1.3–1.38 |
| Второстепенный текст | `#646473`, 29–32 px |
| Заголовок | YS Display Bold, 86–90 px, интерлиньяж 1.03 |
| Обложка | Заголовок до 126 px, подзаголовок около 64 px |
| Акцент | `#5c61db` |
| Светлая подложка | `#f1f2fc` или `#f4f4ff` |
| Разделитель | `#e6e6f0`, 2 px |
| Нижняя подпись | 26 px, нейтральный серый, на тёмном фоне белый |

Это ориентиры исходного визуала. Сначала сокращай лишний текст, затем меняй композицию; уменьшение шрифта — последняя мера. Не заполняй свободное место служебными подписями. Для выбранного пользователем другого формата сохрани иерархию и читаемость.

## Приёмы вёрстки

HTML содержит последовательность `section.slide` с устойчивыми ID. Каждый слайд имеет заголовок, содержимое и нижнюю строку. Даты, URL, название дека, количество и нумерация слайдов задаются текущим материалом.

```css
* { box-sizing: border-box; }
.slide {
  width: 1440px;
  height: 1440px;
  padding: 88px 92px;
  position: relative;
  overflow: hidden;
  display: flex;
  flex-direction: column;
}
.foot {
  margin-top: auto;
  padding-top: 28px;
  display: flex;
  justify-content: space-between;
  font-size: 26px;
}
.step {
  display: flex;
  align-items: center;
  gap: 32px;
}
@media print {
  .slide { margin: 0; break-after: page; }
  @page { size: 1440px 1440px; margin: 0; }
}
```

Нижнюю строку держи в нормальном потоке, оставляя отступ после содержания. Фоновая графика может выходить за границы и обрезаться, текст — нет. Поэтому `scrollHeight` недостаточно: сравнивай границы текстовых блоков с началом нижней строки и проверяй картинки глазами.

## Получение файлов

Используй уже доступный браузерный runtime. Для материалов в Codex пути к библиотекам можно узнать через `load_workspace_dependencies`; не фиксируй версию runtime и абсолютный путь к профилю пользователя в скрипте.

При экспорте через Playwright:

1. Открой локальный HTML в изолированном браузере и дождись `document.fonts.ready`
2. Для каждого `section.slide` сохрани PNG по границам элемента, а не всего viewport
3. Если нужен PDF, создай его с `printBackground: true` и `preferCSSPageSize: true`
4. Создай компактное контактное превью из итоговых PNG, открой его и отдельно проверь изменённые или плотные слайды
5. Проверь, что текст и нижние подписи не пересекаются, счётчик слайдов соответствует экспорту, ссылки ведут на предоставленные адреса
6. Собери архив PNG; если нужен переносимый исходник, собери архив редактируемого HTML со всеми используемыми локальными ассетами. Обновляй их после последней правки, исключай устаревшие картинки при изменении числа слайдов
7. Закрой созданный браузер и останови свои временные серверы

PNG: `slide-01.png`, `slide-02.png` и далее. Остальные результаты: `slides.html`, PDF, `preview.png`, `slides-png.zip`, `slides-source.zip`, `post.md`. Имена можно менять под задачу. Для обычного открытия HTML отдельный сервер не нужен.

QR-код создавай доступным локальным инструментом из точного предоставленного URL, с белым свободным полем вокруг. Проверь распознаваемость и не используй внешнюю службу сокращения ссылок. Если QR-код не добавлялся, кликабельная ссылка и подводка всё равно должны содержать адрес.

## Проверка переноса паттернов

На новой теме убедись, что скилл не навязал содержание старого поста: названия SDD, очереди, бот, теги, дашборд и даты не являются частью визуального шаблона. Для нового дека нужны его собственные факты и CTA. «Лакмус спецификации» относится к содержанию поста про SDD и не добавляется в любой материал автоматически.
